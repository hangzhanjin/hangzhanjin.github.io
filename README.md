# Hangzhan Jin

Personal academic website at [hangzhanjin.github.io](https://hangzhanjin.github.io/).

The site follows the structure of the [al-folio academic template](https://github.com/alshedivat/al-folio) with a small, standalone HTML and CSS implementation.

- Edit the biography, publications, and profile links in `index.html`.
- Edit the design in `styles.css`.
- Replace `assets/Hangzhan-Jin-CV.pdf` with the latest public CV to update the download.
- The portrait comes from the [Mila directory profile](https://mila.quebec/en/directory/hangzhan-jin).

To preview locally, run `python3 -m http.server 8000` in this directory and open `http://localhost:8000/`. GitHub Pages serves the root of the `main` branch without a build step.
